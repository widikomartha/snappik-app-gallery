# SnapPik

SnapPik is a subscription web application that lets photographers share photo selection galleries and deliver finished photographs to clients through a browser.

## Current state

This workspace contains implementation planning documents only. No application, dependencies, database, automated application tests, or deployment has been created. The owner approved the requirements baseline on October 22, 2026; the resulting document package still requires final review. The authoritative approval record is in the [documentation index](docs/index.md).
